# **Dartic**

A comprehensive Flutter-based Dart learning platform with an integrated code editor, real-time compiler, interactive tutorials, and coding challenges. Inspired by DartPad but enhanced with educational features and progress tracking.

## **✨ Features**

### **🎓 Learning Platform**

- 📚 **Complete Dart Course** - Structured tutorials from beginner to advanced
- 🧠 **Interactive Quizzes** - Multiple choice, fill-in-the-blank, and ordering questions
- 📊 **Progress Tracking** - Save and track learning progress across sessions
- 🏆 **Achievement System** - Quiz scoring and course completion tracking

### **💻 Code Editor**

- 🏗️ **Real-time Execution** - Execute Dart code instantly with built-in compiler
- 🎨 **Syntax Highlighting** - Customizable themes (Nord, Atom One Light)
- 📝 **Code Formatting** - Automatic code beautification
- ↩️ **Undo/Redo Support** - Full text editing history
- 💾 **Auto-save** - Automatic code persistence

### **🧩 DSA Challenges**

- 🎯 **Coding Problems** - Data Structures and Algorithms challenges
- ✅ **Test Cases** - Automated testing with multiple test scenarios
- 📈 **Difficulty Levels** - Problems categorized by difficulty
- 🔍 **Solution Validation** - Real-time test execution and results

### **🎨 User Experience**

- 🌗 **Theme Support** - Dark & Light mode with seamless switching
- 🔐 **Authentication** - Google and Apple sign-in integration
- 👤 **User Profiles** - Personalized learning experience
- 📱 **Responsive Design** - Optimized for mobile and tablet

### **🎥 Multimedia Learning**

- 📹 **Video Integration** - Embedded video tutorials
- 📖 **Markdown Support** - Rich text content with code blocks
- 🎬 **Interactive Content** - Lottie animations and visual feedback

## **🎯 Usage**

### **Learning Path**

1. **Sign up** with Google/Apple or continue as guest
2. **Create your profile** and select your Dart skill level
3. **Start with courses** - Follow structured tutorials
4. **Practice coding** - Use the built-in editor
5. **Take quizzes** - Test your knowledge
6. **Solve DSA problems** - Challenge yourself with coding exercises

### **Code Editor Features**

- Write and execute Dart code in real-time
- Use syntax highlighting for better readability
- Access undo/redo functionality
- Format code automatically
- Save your work automatically

### **DSA Challenges**

- Choose from various difficulty levels
- Run test cases to validate solutions
- View detailed test results
- Track your progress
